```javascript

const hasAdminRole = checkPermission('admin')
console.log('是否有管理员权限:', hasAdminRole)

// 测试资源权限
const canCreateProduct = checkPermission({
  resource: 'EXAM_PRODUCT',
  action: 'CREATE'
})
console.log('是否可以创建产品:', canCreateProduct)

// 测试组合权限
const complexPermission = checkPermission({
  and: [
    { roles: ['admin'] },
    { resource: 'USER', action: 'DELETE' }
  ]
})
console.log('复合权限测试:', complexPermission)
```

## 下一步优化计划

根据测试结果，可能需要进行以下优化：

1. **性能优化**
   - 权限检查结果缓存
   - 减少不必要的权限计算
   - 优化权限指令的执行效率

2. **用户体验优化**
   - 改进权限提示信息
   - 优化加载状态显示
   - 增强错误页面设计

3. **代码优化**
   - 重构复杂的权限逻辑
   - 提高代码可维护性
   - 完善类型定义

4. **文档完善**
   - 更新API文档
   - 编写使用指南
   - 准备部署文档
