# 第四阶段：页面组件权限使用指南

## 概述

第四阶段实现了页面内部的细粒度权限控制，包括按钮、表单字段、表格列等组件级别的权限管理。

## 核心功能

### 1. 增强的权限指令

#### 基础用法
```vue
<!-- 角色权限 -->
<el-button v-permission="'admin'">管理员按钮</el-button>
<el-button v-permission="['admin', 'super_admin']">多角色按钮</el-button>

<!-- 资源权限 -->
<el-button v-permission="{ resource: 'USER', action: 'CREATE' }">新增用户</el-button>

<!-- 组合权限 -->
<el-button v-permission="{ 
  and: [
    { roles: ['admin'] },
    { resource: 'USER', action: 'DELETE' }
  ]
}">删除用户</el-button>
```

#### 修饰符用法
```vue
<!-- 隐藏元素（默认） -->
<el-button v-permission="'admin'">按钮</el-button>

<!-- 禁用元素 -->
<el-button v-permission.disable="'admin'">按钮</el-button>

<!-- 移除元素 -->
<el-button v-permission.remove="'admin'">按钮</el-button>
```

### 2. 权限组合函数

#### usePermission
```vue
<script setup>
import { usePermission } from '@/composables/usePermission'

const { 
  hasRole, 
  hasResource, 
  isSuperAdmin, 
  canManageUsers 
} = usePermission()

// 在模板中使用
const showAdvancedFeatures = computed(() => {
  return hasRole(['super_admin', 'admin'])
})
</script>
```

#### usePagePermission
```vue
<script setup>
import { usePagePermission } from '@/composables/usePermission'

const { getTableActions, getFieldPermission } = usePagePermission()

// 获取表格操作权限
const actions = getTableActions('USER', userItem)
// 返回: ['view', 'edit', 'delete']

// 获取字段权限
const fieldPerm = getFieldPermission('USER', 'email', userItem)
// 返回: { readable: true, writable: false, required: true }
</script>
```

### 3. 权限包装组件

#### PermissionWrapper
```vue
<template>
  <!-- 基础用法 -->
  <PermissionWrapper :roles="['admin']">
    <el-card>管理员专用内容</el-card>
  </PermissionWrapper>

  <!-- 资源权限 -->
  <PermissionWrapper 
    resource="USER" 
    action="CREATE"
    show-fallback
  >
    <UserCreateForm />
    <template #fallback>
      <div>您没有创建用户的权限</div>
    </template>
  </PermissionWrapper>

  <!-- 复杂权限配置 -->
  <PermissionWrapper 
    :permission="{
      or: [
        { roles: ['super_admin'] },
        { 
          and: [
            { roles: ['admin'] },
            { resource: 'USER', action: 'READ' }
          ]
        }
      ]
    }"
  >
    <UserManagement />
  </PermissionWrapper>
</template>
```

## 实际应用场景

### 1. 表格权限控制

```vue
<template>
  <el-table :data="tableData">
    <!-- 选择列 - 只有删除权限才显示 -->
    <el-table-column 
      v-permission="{ resource: 'USER', action: 'DELETE' }"
      type="selection" 
    />
    
    <!-- 敏感信息列 - 只有管理员可见 -->
    <el-table-column 
      v-permission="['super_admin', 'admin']"
      prop="salary" 
      label="薪资" 
    />
    
    <!-- 操作列 -->
    <el-table-column label="操作">
      <template #default="scope">
        <el-button 
          v-permission="{ resource: 'USER', action: 'READ' }"
          @click="handleView(scope.row)"
        >
          查看
        </el-button>
        <el-button 
          v-permission="{ resource: 'USER', action: 'UPDATE' }"
          @click="handleEdit(scope.row)"
        >
          编辑
        </el-button>
        <el-button 
          v-permission="{ resource: 'USER', action: 'DELETE' }"
          type="danger"
          @click="handleDelete(scope.row)"
        >
          删除
        </el-button>
      </template>
    </el-table-column>
  </el-table>
</template>
```

### 2. 表单权限控制

```vue
<template>
  <el-form :model="formData">
    <!-- 基础字段 - 所有人可见 -->
    <el-form-item label="姓名">
      <el-input v-model="formData.name" />
    </el-form-item>
    
    <!-- 敏感字段 - 只有管理员可编辑 -->
    <el-form-item 
      v-permission="['super_admin', 'admin']"
      label="工资"
    >
      <el-input-number v-model="formData.salary" />
    </el-form-item>
    
    <!-- 条件字段 - 根据权限禁用 -->
    <el-form-item label="状态">
      <el-select 
        v-permission.disable="{ resource: 'USER', action: 'UPDATE' }"
        v-model="formData.status"
      >
        <el-option label="启用" value="active" />
        <el-option label="禁用" value="inactive" />
      </el-select>
    </el-form-item>
  </el-form>
</template>
```

### 3. 页面功能权限

```vue
<template>
  <div class="page-container">
    <!-- 页面头部操作 -->
    <div class="page-header">
      <h2>用户管理</h2>
      <div class="header-actions">
        <el-button 
          v-permission="{ resource: 'USER', action: 'CREATE' }"
          type="primary"
          @click="handleAdd"
        >
          新增用户
        </el-button>
        
        <!-- 批量操作下拉菜单 -->
        <el-dropdown v-permission="canBatchOperate">
          <el-button>批量操作</el-button>
          <template #dropdown>
            <el-dropdown-menu>
              <el-dropdown-item 
                v-permission="{ resource: 'USER', action: 'CREATE' }"
                command="import"
              >
                批量导入
              </el-dropdown-item>
              <el-dropdown-item 
                v-permission="{ resource: 'USER', action: 'DELETE' }"
                command="batchDelete"
              >
                批量删除
              </el-dropdown-item>
            </el-dropdown-menu>
          </template>
        </el-dropdown>
      </div>
    </div>
    
    <!-- 统计卡片 - 根据权限显示不同内容 -->
    <div class="stats-cards">
      <PermissionWrapper :roles="['super_admin', 'admin']">
        <el-card>
          <div class="stat-item">
            <span class="stat-label">总用户数</span>
            <span class="stat-value">{{ totalUsers }}</span>
          </div>
        </el-card>
      </PermissionWrapper>
      
      <PermissionWrapper :roles="['examiner']">
        <el-card>
          <div class="stat-item">
            <span class="stat-label">我的考生</span>
            <span class="stat-value">{{ myCandidates }}</span>
          </div>
        </el-card>
      </PermissionWrapper>
    </div>
  </div>
</template>

<script setup>
import { computed } from 'vue'
import { usePermission } from '@/composables/usePermission'

const { hasResource, hasRole } = usePermission()

// 计算批量操作权限
const canBatchOperate = computed(() => {
  return hasResource('USER', 'CREATE') || 
         hasResource('USER', 'DELETE') ||
         hasRole(['super_admin', 'admin'])
})
</script>
```

## 最佳实践

### 1. 权限检查原则
- 前端权限控制主要用于UI展示，不能替代后端权限验证
- 敏感操作必须在后端进行二次权限验证
- 权限检查应该尽可能细粒度，但不要过度复杂化

### 2. 性能优化
- 使用 computed 缓存权限检查结果
- 避免在循环中进行复杂权限计算
- 合理使用权限指令的修饰符

### 3. 用户体验
- 对于无权限的功能，提供友好的提示信息
- 使用禁用状态而不是完全隐藏，让用户知道功能存在
- 提供权限申请或联系管理员的途径

### 4. 代码组织
- 将复杂的权限逻辑封装到 composables 中
- 使用 TypeScript 确保权限配置的类型安全
- 保持权限配置的集中管理和维护

## 测试建议

1. **功能测试**：使用不同角色账号测试各功能的权限控制
2. **边界测试**：测试权限边界情况，如角色切换、权限变更等
3. **性能测试**：测试大量权限检查对页面性能的影响
4. **用户体验测试**：确保权限控制不影响正常用户操作流程
