# 权限系统测试指南

## 测试环境准备

### 1. 启动项目
```bash
cd uav-exam-frontend
npm run dev
```

### 2. 测试用户账号

根据当前系统配置，可以使用以下测试账号：

| 角色 | 用户名 | 密码 | 权限范围 |
|------|--------|------|----------|
| super_admin | admin | 123456 | 所有权限 |
| admin | admin | 123456 | 管理员权限 |
| institution | institution | 123456 | 机构用户权限 |
| examiner | examiner | 123456 | 考官权限 |
| candidate | candidate | 123456 | 考生权限 |

## 测试步骤

### 阶段1：基础权限框架测试 ✅

**测试内容：**

**验证方法：**
1. 打开浏览器开发者工具
2. 登录不同角色用户
3. 检查控制台输出的用户信息和权限

### 阶段2：动态菜单系统测试 ✅

**测试内容：**
- [x] 不同角色显示不同菜单
- [x] 菜单项权限过滤
- [x] 面包屑导航

**验证方法：**
1. 使用不同角色登录
2. 观察左侧导航菜单的差异
3. 检查面包屑导航是否正确显示

**预期结果：**
- **super_admin**: 显示所有菜单项
- **admin**: 显示管理相关菜单
- **institution**: 显示机构相关菜单
- **examiner**: 显示考官相关菜单  
- **candidate**: 显示考生相关菜单

### 阶段3：路由权限系统测试 ✅

**测试内容：**
- [x] 路由访问控制
- [x] 未授权访问拦截
- [x] 403/404错误页面

**验证方法：**

#### 3.1 正常访问测试
1. 使用 `admin` 账号登录
2. 点击菜单项，验证可以正常访问有权限的页面
3. 观察控制台路由跳转日志

#### 3.2 权限拦截测试
1. 使用 `candidate` 账号登录
2. 手动在地址栏输入管理员页面URL：
   ```
   http://localhost:3001/exam/products
   http://localhost:3001/personnel/examiners
   http://localhost:3001/settings/system
   ```
3. 验证是否被重定向到403页面

#### 3.3 404页面测试
1. 在地址栏输入不存在的URL：
   ```
   http://localhost:3001/nonexistent-page
   ```
2. 验证是否显示404页面

## 测试检查点

### 控制台日志检查
登录后查看浏览器控制台，应该看到：
```javascript
// 路由跳转日志
路由跳转: {
  from: "/login",
  to: "/dashboard/index", 
  matched: 2,
  routes: ["/", "/dashboard/index"],
  meta: {...}
}

// 用户信息
用户角色: "admin"
权限要求: {...}
```

### 权限验证检查
1. **菜单显示**：不同角色看到不同的菜单项
2. **路由访问**：只能访问有权限的页面
3. **错误处理**：无权限时显示403页面，页面不存在时显示404页面

## 常见问题排查

### 1. 登录后菜单不显示
- 检查用户信息是否正确获取
- 验证权限配置是否正确加载

### 2. 路由跳转失败
- 查看控制台错误信息
- 检查路由配置和组件路径

### 3. 权限检查不生效
- 确认路由元数据配置正确
- 验证权限检查函数逻辑
