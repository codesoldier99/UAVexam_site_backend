# 前端权限系统修改方案

## 📋 现状分析

### 当前权限系统问题
1. **角色定义不完整**：只有 `admin`、`teacher`、`student` 三个角色，缺少 `super_admin`、`institution` 等角色
2. **权限检查逻辑简单**：只支持基础的角色检查，不支持资源级权限控制
3. **菜单权限控制不够细化**：缺少按角色动态显示菜单的机制
4. **路由权限配置不完善**：路由模块中缺少详细的权限配置

```typescript
const hasPermission = (resource: string, action: string, resourceId?: number): boolean => {
  if (!userInfo.value?.role) return false
  
  // super_admin 拥有所有权限
  if (userInfo.value.role === 'super_admin') return true
  
  // 获取权限配置
  const permissionConfig = PERMISSIONS[resource as keyof typeof PERMISSIONS]
  if (!permissionConfig) return false
  
  const allowedRoles = permissionConfig[action as keyof typeof permissionConfig]
  if (!allowedRoles || !Array.isArray(allowedRoles)) return false
  
  // 基础角色权限检查
  if (!allowedRoles.includes(userInfo.value.role)) return false
  
  // 资源级权限检查
  if (resourceId && userInfo.value.role === 'institution') {
    // 机构用户只能操作自己机构的资源
    return checkInstitutionAccess(resource, resourceId, userInfo.value.institution_id)
  }
  
  if (resourceId && userInfo.value.role === 'examiner') {
    // 考官只能操作分配给自己的考试相关资源
    return checkExaminerAccess(resource, resourceId, userInfo.value.id)
  }
  
  if (resourceId && userInfo.value.role === 'candidate') {
    // 考生只能操作自己的资源
    return checkCandidateAccess(resource, resourceId, userInfo.value.id)
  }
  
  return true
}

  if (!userInfo.value?.role) return false
```

```typescript
      return false

    // 递归过滤子菜单
    if (menu.children) {
      menu.children = filterMenusByRole(menu.children, userRole)

        return false
      }
```

### 5. 权限指令增强

**文件**: `src/directives/permission.ts`

```typescript
import { DirectiveBinding } from 'vue'
import { useUserStore } from '@/stores/user'

interface PermissionBinding {
  roles?: string[]
  resource?: string
  action?: string
  resourceId?: number
}

export default {
  mounted(el: HTMLElement, binding: DirectiveBinding) {
    const { value } = binding
    const userStore = useUserStore()
    
    let hasPermission = false
    
    if (Array.isArray(value)) {
      // 兼容旧的角色数组格式
      hasPermission = userStore.hasRole(value)
    } else if (typeof value === 'object') {
      // 新的权限对象格式
      const permission = value as PermissionBinding
      
      if (permission.roles) {
        hasPermission = userStore.hasRole(permission.roles)
      } else if (permission.resource && permission.action) {
        hasPermission = userStore.hasPermission(
          permission.resource,
          permission.action,
          permission.resourceId
        )
      }
    }
    
    if (!hasPermission) {
      // 可以选择隐藏元素或禁用元素
      if (binding.modifiers.hide) {
        el.style.display = 'none'
      } else if (binding.modifiers.disable) {
        el.setAttribute('disabled', 'true')
        el.style.opacity = '0.5'
        el.style.cursor = 'not-allowed'
      } else {
        el.parentNode?.removeChild(el)
      }
    }
  },
  
  updated(el: HTMLElement, binding: DirectiveBinding) {
    // 当权限发生变化时重新检查
    this.mounted(el, binding)
  }
}
```

### 8. 路由守卫增强

**文件**: `src/router/index.ts`

```typescript
// 路由守卫增强
router.beforeEach(async (to, from, next) => {
  NProgress.start()
  
  // 设置页面标题
  document.title = to.meta.title ? `${to.meta.title} - 无人机考试管理系统` : "无人机考试管理系统"
  
  // 检查是否需要登录
  if (to.matched.some(record => record.meta.requiresAuth)) {
    const userStore = useUserStore()
    
    if (!userStore.token) {
      next({
        path: "/login",
        query: { redirect: to.fullPath }
      })
      return
    }
    
    // 如果没有用户信息，尝试获取
    if (!userStore.userInfo) {
      try {
        await userStore.getUserInfo()
      } catch (error) {
        console.error('获取用户信息失败:', error)
        next('/login')
        return
      }
    }
    
    // 检查角色权限
    if (to.meta.roles && !userStore.hasRole(to.meta.roles as string[])) {
      next({ path: "/403" })
      return
    }
    
    // 检查资源权限
    if (to.meta.permissions) {
      const { resource, action, resourceId } = to.meta.permissions as any
      if (!userStore.hasPermission(resource, action, resourceId)) {
        next({ path: "/403" })
        return
      }
    }
    
    next()
  } else {
    next()
  }
})
```

### 在模板中使用权限指令

```vue
<!-- 角色权限 -->
<el-button v-permission="['super_admin', 'admin']">
  创建考试产品
</el-button>

<!-- 资源权限 -->
<el-button v-permission="{ resource: 'EXAM_PRODUCT', action: 'CREATE' }">
  创建考试产品
</el-button>

<!-- 禁用而不是隐藏 -->
<el-button v-permission.disable="['admin']">
  编辑
</el-button>

<!-- 隐藏而不是移除 -->
<el-button v-permission.hide="['admin']">
  删除
</el-button>
```

### 在组件中检查权限

```typescript
import { useUserStore } from '@/stores/user'

const userStore = useUserStore()

// 检查角色权限
const canCreate = userStore.hasRole(['super_admin', 'admin'])

// 检查资源权限
const canEdit = userStore.hasPermission('EXAM_PRODUCT', 'UPDATE', productId)
```

## 🔧 注意事项

1. **向后兼容性**：保留了原有的 `hasPermission` 方法，确保现有代码不会出错
2. **性能优化**：菜单过滤在计算属性中进行，避免重复计算
3. **安全性**：前端权限控制主要用于用户体验，真正的安全验证在后端
4. **扩展性**：权限配置采用配置文件形式，便于后续扩展和维护

这个方案提供了完整的前端权限控制系统，支持角色权限、资源权限、菜单权限和页面权限的全方位控制。
