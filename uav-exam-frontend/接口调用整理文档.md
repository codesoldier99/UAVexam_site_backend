## 3. 后端API接口规范

### 3.1 基础URL配置
- 开发环境: `http://localhost:8000/api/v1`
- 生产环境: 通过环境变量 `VITE_API_BASE_URL` 配置

### 3.2 认证方式
- 使用 Bearer Token 认证
- Token 通过登录接口获取
- 在请求头中添加: `Authorization: Bearer {token}`

### 3.3 响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

## 4. 需要后端提供的接口清单

### 4.1 仪表板接口
- `GET /dashboard/stats` - 获取仪表板统计数据
- `GET /dashboard/exam-stats` - 获取考试数据统计
- `GET /dashboard/pass-rate` - 获取考试通过率
- `GET /dashboard/recent-exams` - 获取最近考试
- `GET /dashboard/activities` - 获取系统活动日志

### 4.2 考试管理接口
- `GET /exams` - 获取考试列表 ⚠️ (当前404错误)
- `POST /exams` - 创建考试
- `GET /exams/{id}` - 获取考试详情
- `PUT /exams/{id}` - 更新考试
- `DELETE /exams/{id}` - 删除考试
- `POST /exams/{id}/publish` - 发布考试
- `POST /exams/{id}/cancel` - 取消考试

### 4.3 人员管理接口
- `GET /api/candidates` - 获取考生列表
- `POST /api/candidates` - 创建考生
- `GET /api/candidates/{id}` - 获取考生详情
- `PUT /api/candidates/{id}` - 更新考生
- `DELETE /api/candidates/{id}` - 删除考生
- `POST /api/candidates/import` - 批量导入考生
- `GET /api/candidates/export` - 导出考生数据

### 4.4 考勤管理接口
- `GET /exams/{examId}/attendances` - 获取考试签到记录
- `POST /exams/{examId}/examiners/{examinerId}/attendance` - 记录考官签到
- `POST /exams/{examId}/candidates/{candidateId}/attendance` - 记录考生签到
- `GET /exams/{examId}/attendance/stats` - 获取考试签到统计

### 4.5 系统设置接口（需要新增）

## 6. 环境配置

### 6.1 环境变量配置
在 `.env.development` 文件中配置：
```
VITE_API_BASE_URL=http://localhost:8000/api/v1
```

在 `.env.production` 文件中配置：
```
VITE_API_BASE_URL=https://your-api-domain.com/api/v1
```

### 6.2 请求拦截器
已配置完整的请求/响应拦截器，包括：
- 自动添加 Authorization 头
- 统一错误处理
- Token 过期自动跳转登录

## 7. 测试建议

1. **接口测试**: 使用 Postman 或类似工具测试所有API接口
2. **错误处理**: 测试网络错误、服务器错误等异常情况

## 8. 注意事项

1. **数据格式**: 确保前后端数据格式一致，特别是日期时间格式
2. **分页参数**: 统一分页参数格式（page, page_size, total）
3. **错误码**: 统一错误码和错误信息格式
4. **文件上传**: 考生导入功能需要支持 multipart/form-data
5. **文件下载**: 考生导出功能需要返回 blob 类型数据
