## 🎯 功能概述

考试排期功能是无人机考试管理系统的核心模块之一，负责为已报名的考生安排具体的考试时间、考场和考官。该功能支持单个排期创建、批量排期、按机构分组排期等多种排期方式，并提供冲突检测、自动分配、状态管理等高级功能。

### 核心价值
- 🎯 **高效排期**: 支持批量创建和自动分配，提高排期效率
- 🔍 **冲突检测**: 智能检测时间、考场、考官冲突，避免排期错误
- 📊 **数据统计**: 提供详细的排期统计和分析报表
- 🏢 **机构管理**: 支持按机构分组排期，满足不同机构需求
- ⚡ **实时同步**: 支持实时更新和通知，确保信息同步

## 🏗️ 系统架构

### 数据模型设计

#### 核心实体关系
```
考试产品 (ExamProduct) 1:N 排期 (Schedule)
考场 (Venue) 1:N 排期 (Schedule)  
排期 (Schedule) N:M 考官 (Examiner)
排期 (Schedule) N:M 考生 (Candidate)
机构 (Institution) 1:N 考生 (Candidate)
```

#### 排期数据模型
```typescript
interface ExamSchedule {
  id: number                      // 排期ID
  examProductId: number           // 考试产品ID
  examProductName: string         // 考试产品名称
  venueId: number                // 考场ID
  venueName: string              // 考场名称
  scheduleDate: string           // 考试日期 YYYY-MM-DD
  startTime: string              // 开始时间 HH:MM:SS
  endTime: string                // 结束时间 HH:MM:SS
  maxCandidates: number          // 最大考生数
  registeredCount: number        // 已报名人数
  checkedInCount: number         // 已签到人数
  status: ScheduleStatus         // 排期状态
  institutionId?: number         // 机构ID（机构专场）
  institutionName?: string       // 机构名称
  examiners: ExaminerInfo[]      // 分配的考官列表
  candidates: CandidateInfo[]    // 参与考生列表
  notes?: string                 // 备注信息
  createdAt: string             // 创建时间
  updatedAt: string             // 更新时间
  createdBy: number             // 创建人ID
  updatedBy: number             // 更新人ID
}

enum ScheduleStatus {
  DRAFT = 'draft',              // 草稿
  PUBLISHED = 'published',      // 已发布
  IN_PROGRESS = 'in_progress',  // 进行中
  COMPLETED = 'completed',      // 已完成
  CANCELLED = 'cancelled'       // 已取消
}
```

## 🚀 功能需求详述

### 阶段一：基础功能（1-2周）

#### 1.1 排期列表管理

**功能描述**: 提供排期的列表展示、搜索、筛选功能

**核心特性**:
- 📋 分页列表展示，支持自定义每页数量
- 🔍 多条件筛选：考试产品、考场、日期范围、状态、机构
- 🔎 关键词搜索：支持考试产品名称、考场名称搜索
- 📊 状态统计：显示各状态排期数量
- ⚡ 快速操作：发布、取消、编辑、删除等操作

**界面要求**:
- 表格形式展示，包含关键信息
- 支持列排序和列宽调整
- 状态用不同颜色标识
- 操作按钮根据权限显示/隐藏

#### 1.2 单个排期创建/编辑

**功能描述**: 创建和编辑单个考试排期

**创建流程**:
1. 选择考试产品
2. 选择考场和时间
3. 分配考官
4. 设置考生容量
5. 可选：预分配考生
6. 冲突检测
7. 保存排期

**表单字段**:
- 考试产品（必填，下拉选择）
- 考场（必填，下拉选择）
- 考试日期（必填，日期选择器）
- 开始时间（必填，时间选择器）
- 结束时间（必填，时间选择器）
- 最大考生数（必填，数字输入）
- 考官分配（必填，多选）
- 考生预分配（可选，穿梭框）
- 机构专场（可选，下拉选择）
- 备注信息（可选，文本域）

**验证规则**:
- 结束时间必须晚于开始时间
- 考生数不能超过考场容量
- 必须分配至少一名考官
- 时间不能与现有排期冲突

#### 1.3 基础冲突检测

**功能描述**: 检测排期创建/编辑时的各种冲突

**检测类型**:
- 🏢 **考场冲突**: 同一考场在同一时间段的重复占用
- 👨‍🏫 **考官冲突**: 同一考官在同一时间段的重复分配
- ⏰ **时间冲突**: 时间段重叠检测
- 👥 **容量冲突**: 考生数量超过考场容量

**冲突处理**:
- 实时检测并提示冲突信息
- 提供冲突详情和建议解决方案
- 支持强制保存（带警告）
- 自动推荐可用时间段

#### 1.4 辅助数据管理

**功能描述**: 提供排期创建所需的基础数据

**数据类型**:
- 考试产品列表
- 考场列表（含容量信息）
- 考官列表（含专业领域）
- 待排期考生列表
- 排期统计数据

### 阶段二：高级功能（2-3周）

#### 2.1 批量排期功能

**功能描述**: 支持批量创建多个排期，提高排期效率

**批量创建方式**:
- 📅 **时间规则批量**: 设置日期范围和时间段规则
- 🏢 **考场批量**: 同时为多个考场创建排期
- 👥 **容量批量**: 根据考生数量自动计算排期数量

**配置参数**:
- 考试产品（单选）
- 考场选择（单选或多选）
- 日期范围（开始日期-结束日期）
- 时间段配置（支持多个时间段）
- 重复规则（周几重复）
- 每场最大考生数
- 考官分配策略
- 自动分配考生选项

**批量创建流程**:
1. 设置批量参数
2. 预览生成的排期列表
3. 批量冲突检测
4. 确认创建
5. 显示创建结果统计

#### 2.2 按机构分组排期

**功能描述**: 为不同机构创建专门的排期，支持机构个性化需求

**分组策略**:
- 🏢 **机构专场**: 每个机构独立排期
- ⚖️ **负载均衡**: 平均分配考试时间
- 📅 **偏好时间**: 考虑机构的时间偏好
- 🎯 **就近原则**: 考虑机构与考场的距离

**配置流程**:
1. 选择参与机构
2. 设置每个机构的考生数量
3. 配置机构偏好（时间、考场）
4. 选择分组策略
5. 自动生成分组方案
6. 手动调整优化
7. 批量创建排期

#### 2.3 自动考生分配算法

**功能描述**: 智能分配考生到合适的排期

**分配算法**:
- 🎲 **随机分配**: 随机分配考生，确保公平性
- ⏰ **时间优先**: 按报名时间先后分配
- 🏢 **机构平衡**: 平衡各机构在不同时间段的分布
- 🎯 **最优匹配**: 综合考虑多个因素的最优分配

**分配约束**:
- 考场容量限制
- 机构集中度控制
- 考生时间偏好
- 特殊需求考生优先

**分配流程**:
1. 选择待分配考生
2. 选择目标排期范围
3. 设置分配策略和约束
4. 执行自动分配算法
5. 预览分配结果
6. 确认并应用分配

#### 2.4 排期状态管理

**功能描述**: 管理排期的生命周期状态

**状态流转**:
```
草稿 → 已发布 → 进行中 → 已完成
  ↓       ↓        ↓
已取消 ← 已取消 ← 已取消
```

**状态操作**:
- 📢 **发布排期**: 考生可见，发送通知
- ❌ **取消排期**: 取消考试，通知相关人员
- ✅ **完成排期**: 考试结束，生成统计报告
- 📝 **编辑排期**: 修改排期信息（限制条件）

**通知机制**:
- 考生通知（短信/邮件/系统消息）
- 考官通知
- 机构通知
- 管理员通知

### 阶段三：优化功能（1-2周）

#### 3.1 排期可视化（日历视图）

**功能描述**: 提供直观的日历视图展示排期信息

- 👨‍🏫 **考官推荐**: 根据专业匹配推荐考官

**推荐算法**:

#### 3.3 导入导出功能

**功能描述**: 支持排期数据的批量导入导出

**导出功能**:

**模板类型**:

### 状态管理 (Pinia Store)

```typescript
// stores/schedule.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { ExamSchedule, ScheduleFilter, BatchScheduleConfig } from '@/types/schedule'
import * as scheduleApi from '@/api/schedule'

export const useScheduleStore = defineStore('schedule', () => {
  // 状态
  const scheduleList = ref<ExamSchedule[]>([])
  const currentSchedule = ref<ExamSchedule | null>(null)
  const loading = ref(false)
  const pagination = ref({
    page: 1,
    size: 20,
    total: 0
  })

  // 计算属性
  const publishedSchedules = computed(() => 
    scheduleList.value.filter(s => s.status === 'published')
  )

  const draftSchedules = computed(() => 
    scheduleList.value.filter(s => s.status === 'draft')
  )

  // 操作方法
  const fetchSchedules = async (filter: ScheduleFilter = {}) => {
    loading.value = true
    try {
      const response = await scheduleApi.getSchedules({
        ...filter,
        page: pagination.value.page,
        size: pagination.value.size
      })
      scheduleList.value = response.items
      pagination.value.total = response.total
    } catch (error) {
      console.error('获取排期列表失败:', error)
    } finally {
      loading.value = false
    }
  }

  const createSchedule = async (data: CreateScheduleForm) => {
    try {
      const response = await scheduleApi.createSchedule(data)
      await fetchSchedules()
      return response
    } catch (error) {
      console.error('创建排期失败:', error)
      throw error
    }
  }

  const updateSchedule = async (id: number, data: Partial<CreateScheduleForm>) => {
    try {
      const response = await scheduleApi.updateSchedule(id, data)
      await fetchSchedules()
      return response
    } catch (error) {
      console.error('更新排期失败:', error)
      throw error
    }
  }

  const deleteSchedule = async (id: number) => {
    try {
      await scheduleApi.deleteSchedule(id)
      await fetchSchedules()
    } catch (error) {
      console.error('删除排期失败:', error)
      throw error
    }
  }

  const batchCreateSchedules = async (config: BatchScheduleConfig) => {
    try {
      const response = await scheduleApi.batchCreateSchedules(config)
      await fetchSchedules()
      return response
    } catch (error) {
      console.error('批量创建排期失败:', error)
      throw error
    }
  }

  const publishSchedule = async (id: number, notifyOptions: NotifyOptions) => {
    try {
      const response = await scheduleApi.publishSchedule(id, notifyOptions)
      await fetchSchedules()
      return response
    } catch (error) {
      console.error('发布排期失败:', error)
      throw error
    }
  }

  const cancelSchedule = async (id: number, reason: string) => {
    try {
      const response = await scheduleApi.cancelSchedule(id, { reason, notify_candidates: true })
      await fetchSchedules()
      return response
    } catch (error) {
      console.error('取消排期失败:', error)
      throw error
    }
  }

  return {
    // 状态
    scheduleList,
    currentSchedule,
    loading,
    pagination,
    
    // 计算属性
    publishedSchedules,
    draftSchedules,
    
    // 方法
    fetchSchedules,
    createSchedule,
    updateSchedule,
    deleteSchedule,
    batchCreateSchedules,
    publishSchedule,
    cancelSchedule
  }
})
```
