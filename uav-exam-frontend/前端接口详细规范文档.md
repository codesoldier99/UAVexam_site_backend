# 无人机考试管理系统 - 前端接口详细规范文档

## 概述
本文档详细列出了前端项目中所有API接口的请求格式、响应格式、数据结构和具体用途。

---

## 1. 认证模块 (auth.ts)

### 1.1 用户登录
**接口**: `POST /api/v1/auth/login`
**用途**: 用户登录认证
**请求数据格式**:
```typescript
{
  username: string;  // 用户名
  password: string;  // 密码
}
```
**响应数据格式**:
```typescript
{
  access_token: string;     // JWT访问令牌
  token_type: string;       // 令牌类型，通常为"Bearer"
  expires_in: number;       // 令牌过期时间（秒）
  user: {
    id: number;             // 用户ID
    username: string;       // 用户名
    email: string;          // 邮箱
    role: string;           // 用户角色：admin, examiner, candidate
    full_name: string;      // 用户全名
  }
}
```

### 1.2 用户登出
**接口**: `POST /api/v1/auth/logout`
**用途**: 用户登出，使令牌失效
**请求数据格式**: 无请求体
**响应数据格式**: 标准成功响应

### 1.3 获取用户信息
**接口**: `GET /api/v1/auth/user-info`
**用途**: 获取当前登录用户的详细信息
**请求数据格式**: 无参数
**响应数据格式**:
```typescript
{
  id: number;               // 用户ID
  username: string;         // 用户名
  email: string;            // 邮箱
  role: string;             // 用户角色
  full_name: string;        // 用户全名
  created_at: string;       // 创建时间 ISO格式
  updated_at: string;       // 更新时间 ISO格式
}
```

### 1.4 修改密码
**接口**: `POST /api/v1/auth/change-password`
**用途**: 修改用户密码
**请求数据格式**:
```typescript
{
  old_password: string;     // 旧密码
  new_password: string;     // 新密码
}
```
**响应数据格式**: 标准成功响应

## 2. 考试管理模块 (exam.ts)

### 2.1 获取考试列表
**接口**: `GET /exams`
**用途**: 获取考试列表，支持分页和筛选
**请求参数**:
```typescript
{
  page?: number;            // 页码，默认1
  page_size?: number;       // 每页数量，默认20
  search?: string;          // 搜索关键词
  status?: string;          // 考试状态：draft, published, ongoing, completed, cancelled
  exam_type?: string;       // 考试类型
  start_date?: string;      // 开始日期筛选 YYYY-MM-DD
  end_date?: string;        // 结束日期筛选 YYYY-MM-DD
}
```
**响应数据格式**:
```typescript
{
  data: Array<{
    id: number;             // 考试ID
    title: string;          // 考试标题
    description: string;    // 考试描述
    exam_type: string;      // 考试类型
    status: string;         // 考试状态
    start_time: string;     // 开始时间 ISO格式
    end_time: string;       // 结束时间 ISO格式
    duration: number;       // 考试时长（分钟）
    total_candidates: number; // 报名考生总数
    checked_in_candidates: number; // 已签到考生数
    created_at: string;     // 创建时间
    updated_at: string;     // 更新时间
  }>;
  total: number;            // 总记录数
  page: number;             // 当前页码
  page_size: number;        // 每页数量
}
```

### 2.2 获取考试详情
**接口**: `GET /exams/{id}`
**用途**: 获取指定考试的详细信息
**请求参数**: 路径参数 id (考试ID)
**响应数据格式**:
```typescript
{
  id: number;               // 考试ID
  title: string;            // 考试标题
  description: string;      // 考试描述
  exam_type: string;        // 考试类型
  status: string;           // 考试状态
  start_time: string;       // 开始时间
  end_time: string;         // 结束时间
  duration: number;         // 考试时长
  max_candidates: number;   // 最大考生数
  registration_start: string; // 报名开始时间
  registration_end: string;   // 报名结束时间
  venue_info: {             // 考场信息
    id: number;
    name: string;
    address: string;
    capacity: number;
  };
  requirements: string[];   // 考试要求
  materials: string[];      // 考试材料
  created_at: string;
  updated_at: string;
}
```

### 2.3 创建考试
**接口**: `POST /exams`
**用途**: 创建新的考试
**请求数据格式**:
```typescript
{
  title: string;            // 考试标题（必填）
  description: string;      // 考试描述
  exam_type: string;        // 考试类型（必填）
  start_time: string;       // 开始时间 ISO格式（必填）
  end_time: string;         // 结束时间 ISO格式（必填）
  duration: number;         // 考试时长分钟（必填）
  max_candidates: number;   // 最大考生数
  registration_start: string; // 报名开始时间
  registration_end: string;   // 报名结束时间
  venue_id: number;         // 考场ID
  requirements: string[];   // 考试要求
  materials: string[];      // 考试材料
}
```
**响应数据格式**: 返回创建的考试详情

### 2.4 更新考试
**接口**: `PUT /exams/{id}`
**用途**: 更新考试信息
**请求数据格式**: 同创建考试，所有字段可选
**响应数据格式**: 返回更新后的考试详情

### 2.5 删除考试
**接口**: `DELETE /exams/{id}`
**用途**: 删除指定考试
**请求参数**: 路径参数 id
**响应数据格式**: 标准成功响应

### 2.6 发布考试
**接口**: `POST /exams/{id}/publish`
**用途**: 发布考试，状态从draft变为published
**请求参数**: 路径参数 id
**响应数据格式**: 标准成功响应

### 2.7 取消考试
**接口**: `POST /exams/{id}/cancel`
**用途**: 取消考试
**请求数据格式**:
```typescript
{
  reason: string;           // 取消原因（必填）
}
```
**响应数据格式**: 标准成功响应

### 2.8 获取考试场次列表
**接口**: `GET /exams/{examId}/sessions`
**用途**: 获取考试的所有场次
**请求参数**: 路径参数 examId
**响应数据格式**:
```typescript
{
  data: Array<{
    id: number;             // 场次ID
    exam_id: number;        // 考试ID
    session_name: string;   // 场次名称
    start_time: string;     // 场次开始时间
    end_time: string;       // 场次结束时间
    venue_id: number;       // 考场ID
    venue_name: string;     // 考场名称
    max_candidates: number; // 最大考生数
    registered_candidates: number; // 已报名考生数
    status: string;         // 场次状态
  }>
}
```

### 2.9 获取考试考生列表
**接口**: `GET /exams/{examId}/candidates`
**用途**: 获取指定考试的考生列表
**请求参数**:
```typescript
{
  page?: number;
  page_size?: number;
  search?: string;          // 搜索考生姓名或身份证
  status?: string;          // 考生状态：registered, checked_in, absent, completed
}
```
**响应数据格式**:
```typescript
{
  data: Array<{
    id: number;             // 考生ID
    name: string;           // 考生姓名
    id_card: string;        // 身份证号
    phone: string;          // 联系电话
    email: string;          // 邮箱
    organization: string;   // 所属单位
    registration_time: string; // 报名时间
    check_in_time: string;  // 签到时间
    status: string;         // 状态
    exam_result?: {         // 考试结果
      score: number;
      result: string;       // pass, fail
      completed_at: string;
    }
  }>;
  total: number;
}
```

## 3. 人员管理模块 (personnel.ts)

### 3.1 获取考生列表
**接口**: `GET /api/candidates`
**用途**: 获取系统中所有考生信息
**请求参数**:
```typescript
{
  page?: number;            // 页码
  page_size?: number;       // 每页数量
  search?: string;          // 搜索关键词（姓名、身份证、电话）
  status?: string;          // 考生状态：active, inactive
  organization?: string;    // 所属单位筛选
  created_start?: string;   // 创建时间开始
  created_end?: string;     // 创建时间结束
}
```
**响应数据格式**:
```typescript
{
  data: Array<{
    id: number;             // 考生ID
    name: string;           // 姓名
    gender: string;         // 性别：male, female
    id_card: string;        // 身份证号
    phone: string;          // 联系电话
    email: string;          // 电子邮箱
    organization: string;   // 所属单位
    status: string;         // 状态：active, inactive
    remark: string;         // 备注
    created_at: string;     // 创建时间
    updated_at: string;     // 更新时间
    exam_history: Array<{   // 考试历史
      exam_id: number;
      exam_title: string;
      exam_date: string;
      result: string;
      score: number;
    }>;
  }>;
  total: number;
}
```

### 3.2 创建考生
**接口**: `POST /api/candidates`
**用途**: 创建新考生
**请求数据格式**:
```typescript
{
  name: string;             // 姓名（必填）
  gender: string;           // 性别（必填）
  id_card: string;          // 身份证号（必填，唯一）
  phone: string;            // 联系电话（必填）
  email: string;            // 电子邮箱（必填）
  organization: string;     // 所属单位（必填）
  status?: string;          // 状态，默认active
  remark?: string;          // 备注
}
```
**响应数据格式**: 返回创建的考生详情

### 3.3 更新考生信息
**接口**: `PUT /api/candidates/{id}`
**用途**: 更新考生信息
**请求数据格式**: 同创建考生，所有字段可选
**响应数据格式**: 返回更新后的考生详情

### 3.4 删除考生
**接口**: `DELETE /api/candidates/{id}`
**用途**: 删除考生（软删除）
**请求参数**: 路径参数 id
**响应数据格式**: 标准成功响应

### 3.5 批量导入考生
**接口**: `POST /api/candidates/import`
**用途**: 通过Excel文件批量导入考生
**请求数据格式**: FormData
```typescript
{
  file: File;               // Excel文件 (.xlsx, .xls)
}
```
**Excel文件格式要求**:
- 第一行为标题行：姓名、性别、身份证号、联系电话、电子邮箱、所属单位、备注
- 性别：男/女 或 male/female
- 身份证号必须唯一且格式正确
- 电话号码格式：11位手机号
- 邮箱格式必须正确

**响应数据格式**:
```typescript
{
  success_count: number;    // 成功导入数量
  error_count: number;      // 失败数量
  errors: Array<{          // 错误详情
    row: number;            // 行号
    error: string;          // 错误信息
    data: object;           // 错误数据
  }>;
}
```

### 3.6 导出考生数据
**接口**: `GET /api/candidates/export`
**用途**: 导出考生数据为Excel文件
**请求参数**: 同获取考生列表的筛选参数
**响应数据格式**: Excel文件流 (Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet)

### 3.7 获取考官列表
**接口**: `GET /api/examiners`
**用途**: 获取系统中所有考官信息
**请求参数**:
```typescript
{
  page?: number;
  page_size?: number;
  search?: string;          // 搜索关键词
  status?: string;          // 考官状态：active, inactive
  certification_level?: string; // 认证级别
  specialization?: string;  // 专业领域
}
```
**响应数据格式**:
```typescript
{
  data: Array<{
    id: number;             // 考官ID
    name: string;           // 姓名
    employee_id: string;    // 工号
    phone: string;          // 联系电话
    email: string;          // 邮箱
    certification_level: string; // 认证级别
    specialization: string[]; // 专业领域
    status: string;         // 状态
    hire_date: string;      // 入职日期
    created_at: string;
    updated_at: string;
    exam_history: Array<{   // 监考历史
      exam_id: number;
      exam_title: string;
      exam_date: string;
      role: string;         // 角色：chief, assistant
    }>;
  }>;
  total: number;
}
```

## 4. 考勤管理模块 (attendance.ts)

### 4.1 获取考试签到记录
**接口**: `GET /exams/{examId}/attendances`
**用途**: 获取指定考试的所有签到记录
**请求参数**:
```typescript
{
  type?: string;            // 人员类型：examiner, candidate, all
  status?: string;          // 签到状态：checked_in, absent
  session_id?: number;      // 场次ID筛选
}
```
**响应数据格式**:
```typescript
{
  data: Array<{
    id: number;             // 签到记录ID
    exam_id: number;        // 考试ID
    person_id: number;      // 人员ID
    person_type: string;    // 人员类型：examiner, candidate
    person_name: string;    // 人员姓名
    person_id_card: string; // 身份证号
    check_in_time: string;  // 签到时间
    status: string;         // 状态：checked_in, absent
    session_id: number;     // 场次ID
    session_name: string;   // 场次名称
    remark: string;         // 备注
  }>;
  summary: {
    total_examiners: number;    // 总考官数
    checked_in_examiners: number; // 已签到考官数
    total_candidates: number;   // 总考生数
    checked_in_candidates: number; // 已签到考生数
    attendance_rate: number;    // 出勤率
  }
}
```

### 4.2 记录考官签到
**接口**: `POST /exams/{examId}/examiners/{examinerId}/attendance`
**用途**: 记录考官签到
**请求数据格式**:
```typescript
{
  session_id: number;       // 场次ID（必填）
```

### 4.3 记录考生签到
**接口**: `POST /exams/{examId}/candidates/{candidateId}/attendance`
**用途**: 记录考生签到
**请求数据格式**: 同考官签到

## 6. 系统设置模块 (settings.ts)

### 6.1 获取系统设置
**接口**: `GET /settings`
**用途**: 获取所有系统设置
**响应数据格式**:
```typescript
{
  basic: {
    system_name: string;      // 系统名称
    version: string;          // 系统版本
    description: string;      // 系统描述
    maintenance_mode: boolean; // 维护模式
    logo_url: string;         // 系统Logo URL
  };
  email: {
    smtp_host: string;        // SMTP服务器
    smtp_port: number;        // SMTP端口
    from_email: string;       // 发件人邮箱
    enable_ssl: boolean;      // 启用SSL
    email_templates: {        // 邮件模板
      exam_notification: string;
      result_notification: string;
    };
  };
  security: {
    min_password_length: number;    // 密码最小长度
    max_login_attempts: number;     // 最大登录尝试次数
    lockout_duration: number;       // 锁定时长（分钟）
    session_timeout: number;        // 会话超时时间（分钟）
    force_https: boolean;           // 强制HTTPS
    enable_two_factor: boolean;     // 启用双因子认证
```

## 9. 数据类型定义

### 9.1 用户角色
- `admin`: 系统管理员
- `examiner`: 考官
- `candidate`: 考生

### 9.2 考试状态
- `draft`: 草稿
- `published`: 已发布
- `ongoing`: 进行中
- `completed`: 已完成
- `cancelled`: 已取消

### 9.3 签到状态
- `checked_in`: 已签到
- `absent`: 缺席

### 9.4 考试结果
- `pass`: 通过
- `fail`: 不通过
- `pending`: 待评定

### 9.5 日期时间格式
- 所有日期时间使用 ISO 8601 格式：`YYYY-MM-DDTHH:mm:ss.sssZ`
- 日期使用格式：`YYYY-MM-DD`
- 时间使用格式：`HH:mm:ss`
