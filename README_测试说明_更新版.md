## 测试结果分析

### 状态码含义

| 状态码 | 含义 | 处理建议 |
|--------|------|----------|
| 200 | 查询成功 | 检查返回的考生信息和考试安排 |

| 422 | 参数验证失败 | 检查请求参数格式 |
| 500 | 服务器错误 | 检查后端服务状态和日志 |

## 常见问题排查

### 1. 登录失败

**问题**: `❌ 登录失败: 401`

**解决方案**:
- 检查用户名密码是否正确
- 确认后端服务是否正常运行
- 检查登录接口路径是否正确

### 2. 查询无结果

**问题**: `❌ 查询失败: 未找到匹配的考生信息`

**可能原因**:
- 考生不存在于数据库中
- 姓名与身份证号不匹配
- 数据库数据未正确初始化

**解决方案**:
- 使用提供的真实测试数据
- 检查数据库是否包含测试数据
- 确认姓名和身份证号完全匹配

### 3. 权限错误

**问题**: `❌ 权限错误: 403`

**解决方案**:
- 确认登录用户角色为考务人员
- 检查token是否有效
- 确认接口权限配置正确

### 4. 网络连接问题

**问题**: `❌ 请求异常: Connection refused`

**解决方案**:
- 确认后端服务正在运行
- 检查服务器地址和端口配置
- 确认防火墙设置

### 5. 没有可签到的考试安排

**问题**: `❌ 没有可签到的考试安排`

**可能原因**:
- 不在签到时间窗口内 (考试前30分钟到考试结束)
- 考生已经签到过
- 考试状态不允许签到
- 没有为该考生安排考试

**解决方案**:
- 检查当前时间是否在签到窗口内
- 确认考生是否已经签到
- 检查数据库中的考试安排数据
