# 手动签到接口文档 - 前端开发指南

## 概述

手动签到功能提供了两步式的签到流程，作为二维码签到的替代方案。前端需要实现两个接口的调用和相应的用户界面。

---

## 接口1: 查询考生信息

### 基本信息
- **接口路径**: `POST /api/v1/wechat/manual-checkin/query`
- **功能**: 根据考生姓名和身份证号查询考生信息和考试安排
- **权限要求**: 需要考务人员权限（ADMIN/SUPER_ADMIN/EXAMINER角色）
- **认证方式**: Bearer Token

### 请求参数

**Content-Type**: `application/json`

**请求体结构**:
```json
{
  "real_name": "string",    // 必填，考生真实姓名
  "id_card": "string"       // 必填，考生身份证号（18位）
}
```

**请求示例**:
```json
{
  "real_name": "张三",
  "id_card": "110101199001011234"
}
```

### 响应结果

**成功响应 (200)**:
```json
{
  "candidate_info": {
    "id": 5,                           // 考生ID，用于后续确认签到

    "phone": "13800138001",            // 电话号码
    "email": "zhangsan@example.com",   // 邮箱（可选）

  "exam_schedules": [
    {
      "schedule_id": 1,                    // 日程ID，用于后续确认签到
      "exam_name": "多旋翼视距内驾驶员理论",   // 考试名称
      "exam_type": "理论",                 // 考试类型

      "venue_name": "北京理论考试教室A",     // 考场名称
```

**错误响应**:

**400 - 业务逻辑错误**:
```json
{
  "detail": "未找到匹配的考生信息"

```

```json
{
  "detail": "未提供有效的认证令牌"
}
```

```json
{
  "detail": "只有考务人员可以进行手动签到操作"
}
```

**422 - 参数验证失败**:
```json
{
  "detail": [
    {
      "loc": ["body", "real_name"],
      "msg": "field required",
      "type": "value_error.missing"
    }

```

## 接口2: 确认手动签到

### 基本信息
- **接口路径**: `POST /api/v1/wechat/manual-checkin/confirm`
- **功能**: 确认执行手动签到操作
- **权限要求**: 需要考务人员权限（ADMIN/SUPER_ADMIN/EXAMINER角色）
- **认证方式**: Bearer Token

### 请求参数

**Content-Type**: `application/json`

**请求体结构**:
```json
{
  "candidate_id": 0,        // 必填，考生ID（从查询接口获取）
  "schedule_id": 0,         // 必填，日程ID（从查询接口获取）
  "operator_info": "string" // 可选，操作员信息（默认使用当前登录用户信息）
}
```

**请求示例**:
```json
{
  "candidate_id": 5,
  "schedule_id": 1,
  "operator_info": "工作人员(张老师)"
}
```

### 响应结果

**成功响应 (200)**:
```json
{
  "success": true,                    // 签到是否成功
  "message": "签到成功",              // 结果消息
  "checkin_info": {
    "checkin_id": 123,               // 签到记录ID
    "checkin_time": "2025-08-28T08:30:00", // 签到时间
    "method": "MANUAL",              // 签到方式
    "operator": "工作人员(张老师)",    // 操作员信息
    "candidate_name": "张三",         // 考生姓名
    "exam_name": "多旋翼视距内驾驶员理论", // 考试名称
    "venue_name": "北京理论考试教室A"   // 考场名称
  }
}
```

**错误响应**:

**400 - 业务逻辑错误**:
```json
{
  "detail": "考生已经签到过，不能重复签到"
}
```

```json
{
  "detail": "不在签到时间窗口内，签到时间为考试开始前30分钟到考试结束"
}
```

```json
{
  "detail": "考试日程不存在或状态不允许签到"
}
```

**401 - 未认证**:
```json
{
  "detail": "未提供有效的认证令牌"
}
```

**403 - 权限不足**:
```json
{
  "detail": "只有考务人员可以进行手动签到操作"
}
```

### 2. JavaScript实现示例

**查询考生信息**:
```javascript
async function queryCandidate(realName, idCard) {
  try {
    const response = await fetch('/api/v1/wechat/manual-checkin/query', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${getToken()}`
      },
      body: JSON.stringify({
        real_name: realName,
        id_card: idCard
      })
    });

    if (response.ok) {
      const data = await response.json();
      displayCandidateInfo(data);
      return data;
    } else {
      const error = await response.json();
      showError(error.detail);
      return null;
    }
  } catch (error) {
    showError('网络请求失败: ' + error.message);
    return null;
  }
}
```

**确认签到**:
```javascript
async function confirmCheckin(candidateId, scheduleId, operatorInfo) {
  try {
    const response = await fetch('/api/v1/wechat/manual-checkin/confirm', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${getToken()}`
      },
      body: JSON.stringify({
        candidate_id: candidateId,
        schedule_id: scheduleId,
        operator_info: operatorInfo
      })
    });

    if (response.ok) {
      const data = await response.json();
      showSuccess('签到成功: ' + data.message);
      displayCheckinResult(data.checkin_info);
      return data;
    } else {
      const error = await response.json();
      showError(error.detail);
      return null;
    }
  } catch (error) {
    showError('网络请求失败: ' + error.message);
    return null;
  }
}
```

### 3. Vue.js组件示例

```vue
<template>
  <div class="manual-checkin">
    <!-- 第一步：查询考生 -->
    <div v-if="step === 1" class="query-step">
      <h3>手动签到</h3>
      <el-form :model="queryForm" :rules="queryRules" ref="queryForm">
        <el-form-item label="考生姓名" prop="realName">
          <el-input v-model="queryForm.realName" placeholder="请输入考生姓名"></el-input>
        </el-form-item>
        <el-form-item label="身份证号" prop="idCard">
          <el-input v-model="queryForm.idCard" placeholder="请输入18位身份证号"></el-input>
        </el-form-item>
        <el-form-item>
          <el-button type="primary" @click="queryCandidate" :loading="loading">
            查询考生信息
          </el-button>
        </el-form-item>
      </el-form>
    </div>

    <!-- 第二步：选择考试安排 -->
    <div v-if="step === 2" class="confirm-step">
      <h3>考生信息确认</h3>
      <div class="candidate-info">
        <p><strong>姓名:</strong> {{ candidateData.candidate_info.real_name }}</p>
        <p><strong>身份证:</strong> {{ candidateData.candidate_info.id_card }}</p>
        <p><strong>机构:</strong> {{ candidateData.candidate_info.institution_name }}</p>
      </div>
      
      <h4>选择要签到的考试</h4>
      <el-radio-group v-model="selectedScheduleId">
        <div v-for="schedule in availableSchedules" :key="schedule.schedule_id" class="schedule-item">
          <el-radio :label="schedule.schedule_id">
            <div class="schedule-info">
              <div class="exam-name">{{ schedule.exam_name }}</div>
              <div class="exam-time">{{ schedule.exam_date }} {{ schedule.start_time }}-{{ schedule.end_time }}</div>
              <div class="venue-name">{{ schedule.venue_name }}</div>
              <el-tag :type="schedule.can_checkin ? 'success' : 'info'">
                {{ schedule.checkin_status }}
              </el-tag>
            </div>
          </el-radio>
        </div>
      </el-radio-group>
      
      <div class="actions">
        <el-button @click="step = 1">返回</el-button>
        <el-button type="primary" @click="confirmCheckin" :loading="loading" :disabled="!selectedScheduleId">
          确认签到
        </el-button>
      </div>
    </div>

    <!-- 第三步：签到结果 -->
    <div v-if="step === 3" class="result-step">
      <div class="success-result">
        <el-icon class="success-icon"><Check /></el-icon>
        <h3>签到成功</h3>
        <div class="checkin-details">
          <p><strong>考生:</strong> {{ checkinResult.candidate_name }}</p>
          <p><strong>考试:</strong> {{ checkinResult.exam_name }}</p>
          <p><strong>考场:</strong> {{ checkinResult.venue_name }}</p>
          <p><strong>签到时间:</strong> {{ formatTime(checkinResult.checkin_time) }}</p>
          <p><strong>操作员:</strong> {{ checkinResult.operator }}</p>
        </div>
        <el-button type="primary" @click="resetForm">继续签到</el-button>
      </div>
    </div>
  </div>
</template>

<script>
export default {
  name: 'ManualCheckin',
  data() {
    return {
      step: 1,
      loading: false,
      queryForm: {
        realName: '',
        idCard: ''
      },
      queryRules: {
        realName: [
          { required: true, message: '请输入考生姓名', trigger: 'blur' }
        ],
        idCard: [
          { required: true, message: '请输入身份证号', trigger: 'blur' },
          { pattern: /^\d{18}$/, message: '请输入18位身份证号', trigger: 'blur' }
        ]
      },
      candidateData: null,
      selectedScheduleId: null,
      checkinResult: null
    }
  },
  computed: {
    availableSchedules() {
      return this.candidateData?.exam_schedules?.filter(s => s.can_checkin) || [];
    }
  },
  methods: {
    async queryCandidate() {
      this.$refs.queryForm.validate(async (valid) => {
        if (valid) {
          this.loading = true;
          try {
            const response = await this.$http.post('/api/v1/wechat/manual-checkin/query', {
              real_name: this.queryForm.realName,
              id_card: this.queryForm.idCard
            });
            
            this.candidateData = response.data;
            this.step = 2;
          } catch (error) {
            this.$message.error(error.response?.data?.detail || '查询失败');
          } finally {
            this.loading = false;
          }
        }
      });
    },
    
    async confirmCheckin() {
      if (!this.selectedScheduleId) {
        this.$message.warning('请选择要签到的考试');
        return;
      }
      
      this.loading = true;
      try {
        const response = await this.$http.post('/api/v1/wechat/manual-checkin/confirm', {
          candidate_id: this.candidateData.candidate_info.id,
          schedule_id: this.selectedScheduleId,
          operator_info: `工作人员(${this.$store.state.user.real_name})`
        });
        
        this.checkinResult = response.data.checkin_info;
        this.step = 3;
        this.$message.success('签到成功');
      } catch (error) {
        this.$message.error(error.response?.data?.detail || '签到失败');
      } finally {
        this.loading = false;
      }
    },
    
    resetForm() {
      this.step = 1;
      this.queryForm = { realName: '', idCard: '' };
      this.candidateData = null;
      this.selectedScheduleId = null;
      this.checkinResult = null;
    },
    
    formatTime(timeString) {
      return new Date(timeString).toLocaleString('zh-CN');
    }
  }
}
</script>
```

### 4. 错误处理建议

**常见错误及处理方式**:

1. **考生不存在**: 提示用户检查姓名和身份证号是否正确
2. **姓名身份证不匹配**: 提示用户重新确认输入信息
3. **没有可签到的考试**: 显示所有考试安排，说明不能签到的原因
4. **重复签到**: 提示考生已经签到过
5. **不在签到时间窗口**: 显示允许签到的时间范围
6. **权限不足**: 提示需要考务人员权限

### 5. 用户体验优化

1. **输入验证**: 实时验证身份证号格式
2. **加载状态**: 显示查询和签到的加载状态
3. **结果反馈**: 清晰显示成功或失败的结果
4. **操作确认**: 签到前显示确认对话框
5. **快速重试**: 失败后提供快速重试选项

## 注意事项

1. **权限控制**: 确保只有考务人员可以访问手动签到功能
2. **时间窗口**: 签到只能在考试开始前30分钟到考试结束期间进行
3. **重复签到**: 系统会阻止同一考生同一场次的重复签到
4. **操作记录**: 所有签到操作都会记录操作员信息，便于审计
5. **网络异常**: 做好网络异常的处理和重试机制

这个接口文档应该能帮助前端开发人员快速理解和实现手动签到功能！
